# Nihal Raj — Portfolio Website

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

## Project structure

```text
Nihal-Portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   │   └── profile.jpg  (add your own photo)
│   ├── resume/          (optional resume PDF)
│   └── icons/           (optional icons)
└── README.md
```

## Preview locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Publish using GitHub Pages

1. Upload the project files and folders to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the deployment to complete.

## Before publishing

- Add your portrait as `assets/images/profile.jpg`.
- Verify all dates, role names, education details, and project descriptions.
- Add a resume PDF if you want one, and link it from the page.
- Confirm your LinkedIn URL and email address.
